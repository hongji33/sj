서진정공 자재 준비 자동화

현대에서 받은 자재소요량 → 라인별 출력 시트 생성 → 날짜별 출력 → 작업 기록 저장

1. 현대 자재소요량 업로드

.xls / .xlsx
현대에서 보내준 파일을 그대로 올리세요. 하루분이든 여러 날분이든 가능합니다. 통합2는 현대의 '통합2' 시트, 2026-07-21 자재소요량 리스트를 기준으로 설계되어 있습니다.

2. 분석 결과

생산번호0
자재 행0
미매칭0
라인0
통합2 처리 기준: 현대 파일의 통합2 시트를 원본 기준으로 사용합니다. SV / SA / SF / SR / AE는 모듈별로 다시 나누지 않고, 현대 자재소요량에 있는 자재코드 그대로 처리합니다.

3. 날짜별 출력

현대 원본의 각 라인별 자료를 따로 출력합니다. 일반 '출력' 파일에서는 KEBAA / HEBAM / HEBAN을 제외하고, 제외한 자료는 각 라인별 통합모델 파일로 따로 생성합니다. 일반 '출력' 시트는 기준 엑셀 Sheet2의 '마샤링' 열(실제 의미: 구분)이 A인 자재만 출력하고, B는 피팅, HOSE는 호스 출력으로 분리합니다.

자동 저장 / 백업

현재 버전은 이 브라우저에 날짜별 작업을 저장합니다. 컴퓨터 고장까지 대비하려면 백업 다운로드 파일을 OneDrive·Google Drive·회사 공용폴더 등에 보관하세요. Firebase 클라우드 저장은 다음 단계에서 연결할 수 있습니다.
